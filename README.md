A deterministic make.fun news-image entry generated with Python standard library only.

The program renders one editorial front page / command-center news wall for Wednesday 25 November 2026. It highlights four same-day story cards:

- Ukraine peace talks, NATO coordination, and Poland AWACS watch.
- Nvidia CEO Jensen Huang returning as the AI chip bellwether face.
- Riyadh / Saudi air-defense alert after a Houthi strike on the tallest-tower skyline.
- Global finance and markets reading the geopolitical and AI-risk tape.

Run:

```bash
python3 -P -s main.py
```

Output goes to `/output/entry.png`, or to `$MAKEFUN_OUTPUT_DIR/entry.png` when the environment variable is set.
